# AstroSouls Guidance — Mystical Glass Website

Responsive static website using HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Website features
- Mystical purple/indigo cosmic theme with glassmorphism.
- Responsive navigation and scroll reveal effects.
- Existing Astrology, Numerology and Personal Guidance content.
- Founder profile for Mrs. Jojan Ahuja.
- FAQ section and enquiry form.
- WhatsApp enquiry handoff with the submitted form details.
- Instagram, Facebook and email links in the footer.
